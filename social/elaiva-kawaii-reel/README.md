# ELåiVA Kawaii Reel

Vertical 9:16 animated Reel concept for ELåiVA — T&S COMPANY.

## Storyboard
1. Kawaii mascot enters from the background.
2. Mascot looks right and left.
3. ELåiVA falls onto its head.
4. Mascot struggles up and drags the ELåiVA name away.
5. 3–4 mascots pop in and dance together.
6. Breaking-news style ELåiVA / AI business message.
7. Original mascot returns holding coffee and a sandwich.
8. It delivers the CTA, then walks away drinking coffee and eating.

The project is intended to run on Vercel and later render a final 1080×1920 MP4.
